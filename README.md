## 📖 Description

**Monochrome Photographer Portfolio** is a clean and atmospheric photography website built around contrast, essential layouts, and black-and-white visual storytelling. The project presents **Nikson Photos**, a photographer portfolio focused on portraits, events, editorial shoots, and honest human moments.

The website includes a bold hero section, an about area, a portfolio gallery, blog-style photography entries, a services section, and a contact form for booking a shoot. Its visual direction relies on a restrained monochrome palette, large photographic compositions, and simple navigation to keep attention on the images.

Each section is designed to communicate a precise photographic identity: minimal, direct, expressive, and centered on light, movement, atmosphere, and personal stories.
